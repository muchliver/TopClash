# 頂尖對戰：數值平衡與 AI 循環賽模擬報告

> 測試指令：`node tools/balance.js`  
> 測試樣本：隨機陣容對戰 N = 6,000 場；AI 風格循環賽每組 300 場。

---

## 1. 核心指標摘要
- **平手率**：1.4%（勝負分明，極少出現判定無效）
- **全殲率**：0.0%（推演雙方均能形成有來有回的交火，未出現單方面一擊秒殺所有部隊的失衡）
- **費用段平均勝率**：
  - **$1 單位**：50.3%（高性價比、伏擊與填補槽位）
  - **$2 單位**：48.8%
  - **$3 單位**：45.1%
  - **$4 單位**：50.3%（性價比黃金中柱）
  - **$5 單位**：49.3%（明星單位戰力卓越，但受限於只能選 1 個且擠壓其餘槽位預算，整體勝率落在健康的 49.3%）
- **極值差距**：全體 50 款裝備中，最高勝率 62.2%（F-22 猛禽），最低勝率 38.0%（PzH 2000 自走砲），處於策略遊戲合理的 40%~60% 區間內。

### 戰術克制關係發現：
1. **空優信徒 (67%)**：憑藉 F-22 的高隱匿空優與長程打擊，在無針對性防空時展現極強統治力。
2. **鋼鐵洪流 (62%)**：在第三階段掌握戰線控制分，對刺蝟與蜂群有壓倒性優勢（70%~79%）。
3. **電戰蜂群 (25%)**：單價低、電戰高但總體耐久度不足，極度仰賴「電磁風暴」事件或特定地圖環境加持。
